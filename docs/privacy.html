Privacy Policy

Notes · Last updated: October 13, 2026 · Español

Notes is a desktop application for personal use. This policy explains what data it handles and what it does with it.

Data stored by the application

Notes (titles, dates, amounts, descriptions, links) and attached files are stored only on the user's computer, inside their home folder. Notes has no servers of its own and does not send this data to the developer. The only exception is the Google Calendar sync described below, which the user turns on if they want it.

Use of Google Calendar

The Google Calendar connection is optional and is turned on by the user. If they turn it on, Notes requests these permissions:

  • See the list of calendars (calendar.calendarlist.readonly), so the user can choose which calendar the due dates are added to.
  • View and edit events (calendar.events), to create, update and delete the events that represent their due dates.

Notes only creates, modifies and deletes the events it created itself (it identifies them with an internal marker). It does not read, modify or delete any other events in the calendar.

Data Notes gets from Google

  • The user's list of calendars (name and identifier), only to show it when choosing the calendar. The name and identifier of the chosen calendar are saved.
  • The events Notes created in that calendar, to update or delete them when the corresponding note changes.

Data Notes sends to Google

For each note, an all-day event is created in the chosen calendar with the title and amount, the date, the description, the links, the installment or repetition, and a reminder. Attached files are never sent. Notes marked as not shown in Google Calendar are not sent.

Storage and protection

Communication is direct between the user's computer and Google, always encrypted (HTTPS). The refresh token issued by Google is stored only on that computer, in a file readable only by the user. The developer does not receive or store any Google data. Data obtained from Google is not transferred to third parties, is not used for advertising or to train models, and is used only for the sync feature described here.

Notes' use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access

From Notes: Google Calendar panel → Disconnect, which revokes access in Google and deletes the token from the computer. Also from the Google account, at myaccount.google.com/permissions. Events already created stay in the calendar and can be deleted manually.

Deleting the data

Uninstalling Notes and deleting the folder ~/.local/share/com.nicolasdri.agenda/ removes all saved notes, attachments and credentials.

Contact
